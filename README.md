# ZeroXFog

A lightweight Minecraft Java resource pack that removes distracting fog while keeping the familiar vanilla visual style.

## Features

- Reduces or removes distance fog.
- Improves visibility in the Overworld, Nether and End.
- Reduces cave fog.
- Keeps the pack lightweight and focused on visual clarity.

## Compatibility

Check the [Modrinth versions page](https://modrinth.com/resourcepack/zeroxfog/versions) for the exact Minecraft versions supported by each release.

## Download

Official releases are published on [Modrinth — ZeroXFog](https://modrinth.com/resourcepack/zeroxfog).

## Installation

1. Download a release ZIP from Modrinth.
2. Place it in your Minecraft `resourcepacks` folder.
3. Enable it under **Options → Resource Packs**.

## Repository contents

This repository currently contains project documentation only. The original editable source files and release ZIPs were not available in the files accessible during repository setup, so no binary release has been represented as source code.
