# ZeroXFog

A Minecraft Java resource pack that removes distracting fog in the Nether, End, and caves while preserving the vanilla visual style.

## Latest Modrinth release

- Version: **1.2** (published 2026-10-10)
- File: `releases/1.2/ZeroFog-Sodium-v2.zip`
- Supports Minecraft Java versions listed on [Modrinth](https://modrinth.com/resourcepack/zeroxfog/versions).

## Features

- Removes dimensional and distance fog.
- Improves visibility in the Overworld, Nether, End, and caves.
- Includes Sodium shader fog support in the published release.
- Preserves the familiar vanilla visual style.

## Installation

Download the ZIP from this repository or [Modrinth](https://modrinth.com/resourcepack/zeroxfog), then place it in `.minecraft/resourcepacks` and enable it in Minecraft's Resource Packs settings.
